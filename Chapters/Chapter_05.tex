\section{Business Context and AI Integration}
%------------------------------

\begin{figure}[htbp]
	\centering
	\includegraphics[width=1\textwidth]{assets/system-workflow.png}
	\caption{Overview system workflow (Updated)}
	\label{fig:system-workflow}
\end{figure}

Figure~\ref{fig:system-workflow} shows the overview of the system workflow. The Borbann AI Agent serves as the central orchestrator, leveraging multiple specialized engines to deliver insights. The AI integration focuses on three key components: Agentic Orchestration, Location Intelligence, and Offline Valuation.

\subsection*{1. Borbann AI Agent (ReAct)}
This is the primary interface for user interaction. Using a ReAct (Reasoning + Acting) pattern, the agent interprets natural language queries ("Is this area good for a cafe?" or "Find 3-bed condos") and orchestrates the necessary tools. This allows for dynamic, context-aware responses rather than static reports.

\subsection*{2. Location Intelligence Engine}
Real estate value is heavily driven by location. This engine acts as a specialized calculator, using widely recognized algorithms to score locations on:
\begin{itemize}
    \item \textbf{Transit:} Connectivity to BTS/MRT and bus networks.
    \item \textbf{Walkability:} density of daily amenities (Groceries, Parks, Cafes).
    \item \textbf{Risks:} Flood and Noise exposure levels.
\end{itemize}

\subsection*{3. Site Analysis \& Valuation}
For commercial users, the Site Analysis component evaluates business potential by analyzing "Magnets" (traffic drivers) vs. "Competitors."
For residential users, the Valuation component provides price estimates using a multi-model approach. This includes a production-ready baseline model (LightGBM) enhanced with Hex2Vec embeddings for spatial context, ensuring reliable performance while advanced Graph Neural Networks (HGT) are being researched.

\section{Goal Hierarchy}
%------------------------------

This section outlines the hierarchical structure of goals for our real estate valuation system.

\subsection{Organizational Goals}
\begin{itemize}
	\item To establish a trusted platform for geospatial intelligence.
	\item To demonstrate the viability of Agentic AI in complex decision support.
\end{itemize}

\subsection{System Goals}
\begin{itemize}
	\item To orchestrate diverse geospatial tools (PostGIS, OSMnx) via a unified Agent interface.
	\item To deliver sub-second responses for location scoring queries.
	\item To provide explainable "Site Scores" for business decision making.
\end{itemize}

\subsection{User Goals}
\begin{itemize}
	\item To gain instant, comprehensive insights about any map location without manual research.
	\item To understand *why* a location is scored a certain way (e.g., "Transit score is high because of the new MRT line").
\end{itemize}

\subsection{AI Model Goals}
\begin{itemize}
	\item \textbf{Agent:} Correctly identify user intent and call the appropriate tool sequence 95\% of the time.
	\item \textbf{Valuation (Hex2Vec + LightGBM):} Provide real-time price predictions with Mean Absolute Percentage Error (MAPE) below 15\% in production.
    \item \textbf{Research (HGT):} Benchmark Heterogeneous Graph Transformer capabilities against the baseline for future deployment.
\end{itemize}

\section{Task Requirements Analysis Using AI Canvas}
%------------------------------

\subsection{AI Task Requirements}

\subsubsection*{1. Borbann AI Agent}
\textbf{Requirements (REQ):} Interpret natural language, manage conversation state, and execute tools based on spatial context (pins/bboxes).
\textbf{Specifications (SPEC):} LangGraph StateGraph with a prebuilt ReAct agent. Tools interact with PostGIS and Python service logic.
\textbf{Environment (ENV):} Interactive web chat; requires handling of ambiguous user queries and potential tool execution failures.

\subsubsection*{2. Location Intelligence Scoring}
\textbf{Requirements (REQ):} Calculate deterministic scores (0-100) for Transit, Walkability, and Schools.
\textbf{Specifications (SPEC):}
\begin{itemize}
    \item \textit{Transit:} Distance decay function from rail stations ($<1km$) + bus stop density.
    \item \textit{Walkability:} Presence of amenity categories within 800m.
    \item \textit{Flood:} Point-in-polygon lookup against flood warning zones.
\end{itemize}
\textbf{Environment (ENV):} High-performance spatial query requirement; utilizes in-memory caching for grid-based pre-calculation.

\subsubsection*{3. Commercial Site Analysis}
\textbf{Requirements (REQ):} Evaluate the viability of a specific business type at a location.
\textbf{Specifications (SPEC):} Heuristic formula: $Score = Base + (Magnets \times W_m) - (Competitors \times W_c)$.
\textbf{Environment (ENV):} Dependent on up-to-date POI data in the \texttt{view\_all\_pois} table.

\section{User Experience Design with AI}
%------------------------------

AI improves user experience by converting complex geospatial data into conversational insights and clear visualizations.

\subsection{Agent-Driven Interaction}
Instead of navigating complex filter menus, users chat with "Borbann AI."
\begin{itemize}
    \item \textbf{Scenario:} User drops a pin and asks "How is the flooding here?"
    \item \textbf{Response:} The agent calls the \texttt{get\_flood\_risk} tool and replies, "This area is in a Yellow Warning zone, historically prone to flash floods during heavy rain."
\end{itemize}

\subsection{Livability Dashboard}
When selecting a location, users see a "Livability Report" card.
\begin{itemize}
    \item \textbf{Visuals:} Radar charts showing the balance between Transit, Leisure, and Schools.
    \item \textbf{Interactivity:} Clicking a score (e.g., Transit) highlights the nearby stations contributing to that score on the map.
\end{itemize}

\subsection{Site Potential Analysis}
For business users:
\begin{itemize}
    \item \textbf{Input:} Select "Cafe" and click a location.
    \item \textbf{Output:} "Site Score: 78/100. High Potential. 3 Office Buildings nearby serves as magnets, with only 1 direct competitor within 500m."
\end{itemize}

\section{Deployment Strategy}
%------------------------------

\subsection{Deployment Plan}
The system is deployed as a containerized microservices architecture on Google Cloud Platform.

\subsubsection{Components}
\begin{itemize}
    \item \textbf{Frontend:} Static asset serving (CDN).
    \item \textbf{Backend API:} FastAPI service hosting the Agent Graph and Intelligence Engine.
    \item \textbf{Database:} Cloud SQL for PostgreSQL (handling PostGIS and pgvector workloads).
    \item \textbf{AI Models:}
    \begin{itemize}
        \item \textbf{LLM:} Vertex AI (Gemini Pro) for reasoning and tool orchestration.
        \item \textbf{Production Model:} LightGBM regressor augmented with Hex2Vec spatial embeddings, served via FastAPI.
        \item \textbf{Experimental Model:} Heterogeneous Graph Transformer (HGT) under active research for handling complex relationship modeling.
    \end{itemize}
\end{itemize}
